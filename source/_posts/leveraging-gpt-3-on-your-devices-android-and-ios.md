## Using ChatGPT Through a Smartphone Web Browser

 On both Android and iOS devices, you can use your phone's web browser to access ChatGPT (if you'd prefer to avoid using the official ChatGPT apps). You need to create an account, launch the website through your smartphone web browser, and you're good to go.

1. Open any web browser and visit [chat.openai.com](http://chat.openai.com), the official ChatGPT website.
2. Login using your credentials (or sign up if you aren't yet registered).
3. Once you're done signing up/logging in, you'll be greeted by a few disclaimers. Tap **Next** for all of these, and then tap **Done** to start using ChatGPT.

## Using ChatGPT Through Siri Shortcuts

 Siri is a great virtual assistant but can't hold a candle to ChatGPT. However, if you ever wanted Siri to be more capable, you can combine ChatGPT with Siri. This method involves Siri Shortcuts, API keys for ChatGPT, and a little patience. Make sure you already have an OpenAI account before you proceed.

 Please note that this method requires you to add a payment method to your OpenAI account, which will then be charged based on how much you use ChatGPT. To understand this better, check out [ChatGPT API pricing](https://openai.com/pricing) and be sure that you know [how API tokens work](https://www.makeuseof.com/what-is-chatgpt-token-limit-can-you-exceed-it/).

1. Open the [SiriGPT shortcut page](https://www.icloud.com/shortcuts/18cd4aad0abe4b4ebcc03ef3b4d0dc40), and your iPhone will ask you to open the file in the Shortcuts app. From here, tap **Add Shortcut**.
2. Get your OpenAI API keys by visiting [platform.openai.com](https://platform.openai.com/account/api-keys). Then, log into your OpenAI account, and tap the **menu icon** (three horizontal lines) in the top-right corner of your screen.
3. Tap your profile icon at the bottom of the menu, then tap **View API keys**.
4. Next, tap **Create new secret key** and tap the **copy icon** to copy it to your clipboard. Tap **OK** to close the window.
5. You must add this API key to the SiriGPT shortcut we installed earlier. Open the Shortcuts app, find the SiriGPT short, and tap the **three dots** to edit the shortcut.
6. Paste your API key in place of the **Add API Key Here** placeholder text.
7. Go back to the Shortcuts menu and tap the SiriGPT shortcut. It will ask your permission to enable Speech Recognition for the shortcut. Tap **Allow**.
8. Run the shortcut again and ask it a question. Another pop-up will appear asking you to allow the shortcut to send text to the OpenAI API. Tap **Always Allow**.
9. Finally, you'll now get an answer in the voice of Siri. Tap **Done** or **Ask Again** if you want to give it another prompt.

## Third-Party ChatGPT Apps for Android and iOS

 If the official ChatGPT app is unavailable in your area, third-party apps are a great alternative. They provide a much more stable UI than the web version but don't just go with any third-party app with "chat" and "GPT" in its title. Most apps are garbage and want to steal your information—or worse.

 If you have an iPhone, you should give [Perplexity](https://apps.apple.com/us/app/perplexity-ask-anything/id1668000334) a try. The app uses an AI-powered search engine and replicates a lot of the functionality of ChatGPT—one reason being that it's based on OpenAI's GPT technology. However, its purpose is slightly different because it is a search engine that fulfills text generation requests well. Perplexity can also provide sources for its answers, search the internet for real-time information, and even allows you to search by voice.

## Protect Yourself From Scams

 Amid all the excitement with AI, staying on your toes is important. You can easily fall victim to apps that steal your data, charge you for no reason, or annoy you with a constant barrage of ads.

 Your best bet is to go with the official app or use the web version in the absence of it. But, then, the Siri Shortcuts method is great, too. Furthermore, if you need a third-party ChatGPT app, stick with our recommendations. However, if you want the best experience, stick to the official ChatGPT website or the official ChatGPT app, or try Microsoft's Bing AI Chat.
